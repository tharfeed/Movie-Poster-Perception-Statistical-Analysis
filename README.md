# Movie-Poster-Perception-Statistical-Analysis
This repository contains our team’s experimental analysis on how the presence of actor names on horror movie posters influences perceived scariness. Using edited posters and survey data, we test the hypothesis that actor name recognition reduces emotional fear response in audiences.

## Contributing Team Members
Arundhati Kolahal, Shiv Nag, Shreya Lodha, Tharfeed Ahmed Unus, Yash Kothari 

## Features and Findings
- Research Question: Does adding actor names to horror movie posters change how scary they seem?
- Hypothesis: Posters with actor names reduce perceived scariness due to familiarity and comfort.
- Method: We used five posters in original and actor-name-edited versions and surveyed audience reactions.
- Key Insight: Our initial findings suggest that recognizable actor names may lessen the emotional impact of horror visuals, aligning with psychological theories on familiarity and affective response.
